# Browser Prototype

This directory contains a dependency-free browser prototype for the overtime application.

## Run
Open `prototype/index.html` in a browser.

## What can be tested
- Overtime application input
- Automatic overtime duration calculation
- Draft save in browser localStorage
- Submit simulation
- Approval screen preview
- Approve / return / reject actions
- Required comment validation for return/reject

## Important
This is UI/flow validation only. It has no server, authentication, database, email delivery, PDF generation or production security yet. Sample employee data is fictional.
